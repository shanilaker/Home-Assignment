# חנות קטנה - מערכת הזמנות מינימלית

מערכת Web מינימלית לעסק קטן שמוכר מוצרים: לקוח רואה מוצרים (מגיעים מ-DB), בוחר מוצר ומבצע הזמנה שנשמרת ב-DB, וצד העסק יכול לצפות בהזמנות שנוצרו.

## סטאק טכנולוגי

- **Frontend:** HTML / CSS / JavaScript סטטי (ללא framework, ללא build step).
- **Database:** Supabase (Postgres), עם קריאה/כתיבה ישירות מהדפדפן דרך ה-JS SDK.
- **Deployment:** Vercel (סטטי, מחובר ל-GitHub).

בחרתי בגישה הזו (סטטית, בלי שרת backend נפרד) כי Supabase כבר חושף API מלא (REST + JS SDK) על ה-DB, כך שכתיבת backend משלי הייתה שכבה מיותרת בהתחשב בשעון של 180 דקות - זה מוריד סיכון פריסה, שהוא בדרך כלל הצוואר בקבוק הכי מסוכן בתרגיל כזה.

## איך מריצים מקומית

1. פותחים את `supabaseClient.js` וממלאים את ה-`SUPABASE_URL` וה-`SUPABASE_ANON_KEY` מהפרויקט ב-Supabase.
2. מריצים את `schema.sql` בלשונית ה-SQL Editor בפרויקט ה-Supabase (יוצר טבלאות, RLS, נתוני seed, ופונקציית `place_order`).
3. פותחים את `index.html` בדפדפן (או מריצים שרת סטטי מקומי, למשל `npx serve`).

## מבנה הפרויקט

```
index.html         - עמוד המוצרים והזמנה (צד לקוח)
orders.html         - עמוד צפייה בהזמנות (צד עסק)
app.js              - לוגיקת עמוד המוצרים
orders.js           - לוגיקת עמוד ההזמנות
supabaseClient.js   - חיבור ל-Supabase (URL + key)
styles.css          - עיצוב משותף
schema.sql          - סכמת ה-DB, RLS policies, seed data, ופונקציית place_order
```

## דרישה נוספת שנבחרה: ניהול מלאי (Stock)

כל מוצר כולל שדה `stock`. הזמנה חדשה עוברת דרך פונקציית Postgres בשם `place_order` שבודקת את המלאי הזמין, מקטינה אותו, ויוצרת את ההזמנה - הכל **בטרנזקציה אטומית אחת** (עם `for update` שנועל את השורה). זה מונע מצב שבו שני לקוחות מזמינים בו-זמנית את הפריט האחרון ושניהם "מצליחים" (overselling).

## החלטות מרכזיות

- **סטאק סטטי בלי backend נפרד** - Supabase מספק DB + API מוכנים, אז שכבת שרת משלי הייתה מיותרת ומוסיפה סיכון פריסה.
- **ניהול מלאי דרך RPC אטומי** ולא "קרא מלאי ב-JS ואז כתוב" - כדי למנוע race condition.
- **קריאת orders ציבורית** (ללא הזדהות) - כדי לפשט את התרגיל בזמן הנתון. בסביבת אמת הייתי מוסיף הזדהות (למשל Supabase Auth) לעמוד `orders.html` כדי שרק בעל העסק יוכל לצפות בו.
